# Medien

- `roomtour-villa.mp4`: eigenes Roomtour-Video (H.264, möglichst unter 15 MB, wird stumm abgespielt). Hochkant (1080×1920, wie Reels/TikTok) oder quer (1920×1080): die Seite erkennt das Format und passt das Layout an. Keine fremden Videos und keine Wasserzeichen (z. B. TikTok-Logo).
- `roomtour-villa.jpg`: Standbild aus dem Video, wird angezeigt, bis das Video lädt.

Die Kapitel-Positionen stehen in `public/studio/index.html` unter `CHAPTERS` (Anteil der Videolänge, 0 bis 1).
